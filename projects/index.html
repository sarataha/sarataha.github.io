agent-kit

A Claude Code setup for running coding agents mostly on their own: spec, build, CI and review loops, and a risk check before merge. Acceptance tests are written by a separate agent and locked by hooks, review never comes from the session that wrote the code, and risky paths and merges stay with a human.
